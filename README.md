# PetInn: Your Pet-Friendly Getaway

Une plateforme comme booking.com permettant aux propriétaires de chiens de trouver des locations 100% pet-friendly (hôtel, camping, villa, village vacances,...) en France. Avec une réservation directement sur la plateforme. Le nom de la plateforme est PetInn.

- Page d'accueil et recherche d'hébergements en France avec filtres pet-friendly (jardin clôturé, gabarit/taille acceptée, équipements fournis).
- Demande de réservation préalable validée manuellement par l'hébergeur pour lui laisser le temps de confirmer que son logement convient aux animaux.
- Commission de service payée uniquement par le voyageur.
- Passeport canin avec les informations essentielles (nom, taille/poids, race, comportement) pour simplifier chaque demande.
- Espace pour les hébergeurs pour gérer les demandes de réservation et consulter les profils des chiens.
